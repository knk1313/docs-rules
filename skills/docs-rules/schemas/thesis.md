# 学位論文（thesis）

書き方の型は[README.md](README.md)を参照。根拠にした資料と、採否の判断は[references/paper-sources.md](../references/paper-sources.md)にある。

## 目的と読み手

- 目的：学位（博士、修士、学士）を申請するための日本語の論文を書く。研究の全体を一つの文書にまとめ、審査を受けられる形にする
- 読み手：審査する教員と、同じ分野の研究者。研究の背景の知識はあるが、この研究の詳細は知らない前提で書く
- 対象外：学会誌に投稿する論文（[journal-paper.md](journal-paper.md)で扱う）、英語の論文と英文の要旨、大学ごとの様式の差（表紙、製本、ページ番号の位置、字数の上限）。様式の差は、利用者の指定に従う
- 位置づけ：学会論文と同じく、Diátaxisの4分類の外。学会論文との違いは、目次を置くこと、要旨を目次の後に置くこと、複数の研究を一つの文書にまとめられることである

## 入力

- 研究の目的と仮説、方法の記録、データと分析の結果、図表
- 参照した文献の一覧
- 大学と研究科の論文の様式。ある場合は、このスキーマより様式を優先する
- 学会論文（[journal-paper.md](journal-paper.md)）を入力にできる。対応は次の表のとおり

| 学会論文のセクション | 学位論文で使うセクション |
| --- | --- |
| `## 要旨` | `## 要旨`（学位論文の全体の要旨に書き直す） |
| `## キーワード` | 使わない |
| `## 序論`、`## 関連研究` | `## 序論`、`## 関連研究` |
| `## 方法`、`## 結果`、`## 考察` | 同じ見出し。複数の研究をまとめるときは、研究ごとに`###`で分ける |
| `## 結論` | `## 結論` |
| `## 参考文献` | `## 参考文献` |

## 必須セクション

学位論文には、次のセクションを表の順に置く。

| 順 | 見出し名 | 役割 |
| --- | --- | --- |
| 1 | `## 目次` | 文書の`##`と`###`の見出しを順に並べる |
| 2 | `## 要旨` | 研究の目的、方法、主な結果、結論を、本文を読まなくても分かるように示す |
| 3 | `## 序論` | 背景、解く問題、この研究の目的と貢献、論文の構成を示す |
| 4 | `## 関連研究` | 先行研究を示し、この研究との違いを示す |
| 5 | `## 方法` | 第三者が検証できる詳しさで、対象、材料、手順、分析の方法を示す |
| 6 | `## 結果` | 得られた事実を、解釈を交えずに示す |
| 7 | `## 考察` | 結果の解釈、先行研究との比較、研究の限界を示す |
| 8 | `## 結論` | 分かったこと、貢献、残った課題を示す |
| 9 | `## 参考文献` | 本文で参照した文献を、参照の方式に合わせて並べる |

## セクションごとの書き方

### 目次

- 書くこと：`## 目次`より後ろにある`##`と`###`の見出しを、文書の順に並べる
- 書かないこと：見出しの説明、`####`以下の見出し
- 粒度の目安：1見出し1行の番号なしの箇条書にし、`###`の見出しは1段字下げする。見出しの文字列は本文の見出しと一字も変えない

### 要旨

- 書くこと：研究の目的、方法、主な結果、結論。複数の研究をまとめた場合は、研究ごとの結果を一つずつ書く
- 書かないこと：参考文献の参照、図表の参照、本文で説明する細かい条件
- 粒度の目安：大学や研究科の規定の字数に収める。規定がなければ、序論から結論までの各セクションの要点を1〜2文ずつ書く。結果には数値を一つ以上入れる

### 序論

- 書くこと：研究の背景、解く問題、先行研究で足りない点の要点、この研究の目的と貢献、論文の構成
- 書かないこと：方法の詳細、結果、先行研究の詳しい紹介
- 粒度の目安：目的は1文で書き、「本研究の目的は」のように目的と分かる形にする。論文の構成は、`##`の見出しごとに何を書くかを1文ずつ示す

### 関連研究

- 書くこと：先行研究を観点ごとに分けて示し、観点ごとにこの研究との違いを書く。各先行研究に参考文献の番号を付ける
- 書かないこと：この研究の方法と結果、本文で使わない文献の紹介
- 粒度の目安：観点ごとに`###`の見出しを一つ置く。先行研究と違う点を、観点ごとに1文以上書く

### 方法

- 書くこと：対象（参加者、試料、データ）、材料と道具、手順、分析の方法。人を対象にした研究では、倫理面の手続きも書く
- 書かないこと：結果、結果の解釈
- 粒度の目安：同じ分野の研究者が同じ手順を再現できる詳しさにする。条件と量は数値と単位で書く。複数の研究をまとめるときは、研究ごとに`###`で分ける

### 結果

- 書くこと：得られた事実を、重要な順に書く。予想に反した結果も省かない。図表を使うときは、本文で図表の番号を挙げて参照する
- 書かないこと：結果の解釈や意見（「考察」に書く）、方法の説明
- 粒度の目安：数値には単位を付ける。統計的な検定を使った場合は、検定の名前、統計量、効果量を書く。研究ごとの分け方は、「方法」と同じ`###`の見出しにそろえる

### 考察

- 書くこと：結果の解釈、序論で示した目的や仮説との対応、先行研究との比較、研究の限界。複数の研究をまとめた場合は、研究を通した考察も書く
- 書かないこと：「結果」に出していない新しい結果、序論の繰り返し
- 粒度の目安：解釈ごとに1段落。各解釈がどの結果に基づくかを、結果の数値か図表の番号で示す

### 結論

- 書くこと：この研究で分かったこと、貢献、残った課題
- 書かないこと：新しい議論、考察の繰り返し
- 粒度の目安：1〜3段落。残った課題は一つ以上書く

### 参考文献

- 書くこと：本文で参照した文献すべて。各文献に、著者、題名、誌名か書名、巻と号、ページ、発行年を書く。Webの資料には、URLと参照した日を加える
- 書かないこと：本文で参照していない文献
- 粒度の目安：1文献1項目。番号方式では、本文で参照した順に番号を付けて並べる。既定の書き方は、学会論文の`## 参考文献`の粒度の目安と同じにする

## 文書全体の制約

学会論文（[journal-paper.md](journal-paper.md)）の「文書全体の制約」を、次の点を除いてそのまま当てはめる。評価するときは、学会論文の「文書全体の制約」も読む。

1. 見出しと構成の2：文書名（`#`）は論文の題名にする。題名の直後に、学位の種類、所属、氏名、提出日を本文として書く
2. 見出しと構成の3：任意の`## 謝辞`を置く位置は、学会論文と同じく`## 結論`と`## 参考文献`の間にする。任意の`## 付録`は、`## 参考文献`の後ろに置く（九州大学の大学院医学系、参照のみ）
3. 文体の2：箇条書を使わない範囲は、`## 序論`から`## 結論`までの本文にする。`## 目次`と`## 参考文献`は対象外にする
