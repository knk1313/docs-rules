# 学会論文（journal-paper）

書き方の型は[README.md](README.md)を参照。根拠にした資料と、採否の判断は[references/paper-sources.md](../references/paper-sources.md)にある。

## 目的と読み手

- 目的：学会誌や論文誌に投稿する日本語の論文の原稿を書く。研究の目的、方法、結果を、同じ分野の研究者が検証できる形で示す
- 読み手：同じ分野の研究者と査読者。研究の背景の知識はあるが、この研究の詳細は知らない前提で書く
- 対象外：学位論文（[thesis.md](thesis.md)で扱う）、英語の論文と英文の要旨、学会ごとの投稿規定の差（文字数の上限、段組、書式ファイル）。投稿規定の差は、利用者の指定に従う
- 位置づけ：Diátaxisの4分類の外。背景と考察は解説に近く、方法と結果はリファレンスに近いが、研究を報告する構成はこのスキーマで独自に定める（[README.md](README.md)の「文書種別の決め方」）

## 入力

- 研究の目的と仮説、方法の記録、データと分析の結果、図表
- 参照した文献の一覧
- 投稿先の投稿規定。ある場合は、このスキーマより投稿規定を優先する

## 必須セクション

学会論文には、次のセクションを表の順に置く。

| 順 | 見出し名 | 役割 |
| --- | --- | --- |
| 1 | `## 要旨` | 目的、方法、主な結果、結論を、本文を読まなくても分かるように示す |
| 2 | `## キーワード` | 論文の内容を表す語を並べる |
| 3 | `## 序論` | 背景、解く問題、この研究の目的と貢献を示す |
| 4 | `## 関連研究` | 先行研究を示し、この研究との違いを示す |
| 5 | `## 方法` | 第三者が検証できる詳しさで、対象、材料、手順、分析の方法を示す |
| 6 | `## 結果` | 得られた事実を、解釈を交えずに示す |
| 7 | `## 考察` | 結果の解釈、先行研究との比較、研究の限界を示す |
| 8 | `## 結論` | 分かったこと、貢献、残った課題を示す |
| 9 | `## 参考文献` | 本文で参照した文献を、参照の方式に合わせて並べる |

## セクションごとの書き方

### 要旨

- 書くこと：研究の目的、方法、主な結果、結論。本文を読まなくても要点が分かるように書く
- 書かないこと：参考文献の参照、図表の参照、本文で説明する細かい条件
- 粒度の目安：投稿先の規定の字数に収める。規定がなければ600字以内にする。結果には数値を一つ以上入れる

### キーワード

- 書くこと：論文の内容を表す語。題名と要旨に出ない語を入れてもよい
- 書かないこと：「研究」「分析」のように、どの論文にも当てはまる語
- 粒度の目安：投稿先が指定する数にする。指定がなければ3〜5語にする。番号なしの箇条書で、1行に1語を書く

### 序論

- 書くこと：研究の背景、解く問題、先行研究で足りない点の要点、この研究の目的と貢献
- 書かないこと：方法の詳細（「方法」に書く）、結果（「結果」に書く）、先行研究の詳しい紹介（「関連研究」に書く）
- 粒度の目安：3〜5段落。目的は1文で書き、「本研究の目的は」のように目的と分かる形にする

### 関連研究

- 書くこと：先行研究を観点ごとに分けて示し、観点ごとにこの研究との違いを書く。各先行研究に参考文献の番号を付ける
- 書かないこと：この研究の方法と結果、本文で使わない文献の紹介
- 粒度の目安：観点ごとに1段落か、`###`の見出し一つ。先行研究と違う点を、観点ごとに1文以上書く。分野の慣行で先行研究を序論の中で述べる場合は、その旨を1文で書き、序論を参照させる

### 方法

- 書くこと：対象（参加者、試料、データ）、材料と道具、手順、分析の方法。人を対象にした研究では、倫理面の手続きも書く
- 書かないこと：結果、結果の解釈。既刊の論文と同じ方法は、その論文を参照して記述を短くする
- 粒度の目安：同じ分野の研究者が同じ手順を再現できる詳しさにする。条件と量は数値と単位で書く

### 結果

- 書くこと：得られた事実を、重要な順に書く。予想に反した結果も省かない。図表を使うときは、本文で図表の番号を挙げて参照する
- 書かないこと：結果の解釈や意見（「考察」に書く）、方法の説明
- 粒度の目安：数値には単位を付ける。統計的な検定を使った場合は、検定の名前、統計量、効果量を書く

### 考察

- 書くこと：結果の解釈、序論で示した目的や仮説との対応、先行研究との比較、研究の限界
- 書かないこと：「結果」に出していない新しい結果、序論の繰り返し
- 粒度の目安：解釈ごとに1段落。各解釈がどの結果に基づくかを、結果の数値か図表の番号で示す

### 結論

- 書くこと：この研究で分かったこと、貢献、残った課題
- 書かないこと：新しい議論、考察の繰り返し
- 粒度の目安：1〜3段落。残った課題は一つ以上書く

### 参考文献

- 書くこと：本文で参照した文献すべて。各文献に、著者、題名、誌名か書名、巻と号、ページ、発行年を書く。Webの資料には、URLと参照した日を加える
- 書かないこと：本文で参照していない文献
- 粒度の目安：1文献1項目。番号方式では、本文で参照した順に番号を付けて並べる。既定の書き方は、論文なら`山田太郎「論文名」『誌名』第10巻第2号、1〜10ページ、2025年`、書籍なら`山田太郎『書名』発行所、2025年`とする

## 文書全体の制約

次の制約は、共通ルール（[rules/](../rules/README.md)）に加えて当てはめる。共通ルールの例外と書いたものは、この種別では共通ルールより優先する。根拠のうち「参照のみ」の資料は、考え方だけを使い、文章は写していない。

### 見出しと構成

1. 見出しは[README.md](README.md)の「見出しの規約」に従う。`##`の見出し名は表のとおりにし、番号を付けない。番号付きの見出しを求める投稿先には、提出のときに番号を付ける
2. 文書名（`#`）は論文の題名にする。著者名と所属は、文書名の直後に本文として書く
3. 任意の`## 謝辞`は、`## 結論`と`## 参考文献`の間に置ける。「見出しの規約」の例外である。任意の`## 付録`は、`## 参考文献`の後ろに置く（SIST 08、情報処理学会、参照のみ）

### 文体

1. 文体は常体（である調）にそろえる。GRM-001の例外で、常体と敬体のどちらにそろえるかを常体に決める（日本科学教育学会、日本看護研究学会、参照のみ）
2. `## 序論`から`## 結論`までの本文では、箇条書を使わず、文で書く。GRM-003の例外である。`## キーワード`と`## 参考文献`は対象外にする（日本心理学会、参照のみ）
3. 本文に体言止めと話し言葉を使わない（日本心理学会、参照のみ）
4. 自分の既刊の論文を参照するときは、「著者は」と書かず、著者名と発行年で書く（日本心理学会、参照のみ）。一人称のそのほかの扱いは、根拠になる規定がないため定めない

### 略語と記号

1. 題名に略語を使わない（SIST 08、九州大学の大学院医学系、参照のみ）
2. 略語の初出で正式名称を示すことは、NOT-005に従う。加えて、要旨で正式名称を示した略語も、本文の初出で改めて示す（九州大学の大学院医学系、参照のみ）
3. 本文で使う記号には、初めて使う箇所で意味を書く（人工知能学会、参照のみ）

### 数値と単位

1. 数値と単位記号の間に空白を1字入れる。平面角の度、分、秒には入れない（SI第9版）
2. 単位記号にピリオドと複数形を付けない。「sec」「cc」のような略し方をせず、「s」「cm³」のように単位記号で書く（SI第9版）
3. 量記号は斜体（Markdownでは`*`で囲む）、単位記号は直立体で書く（SI第9版）

### 図表

1. 図と表は、それぞれ本文に出る順で通し番号を振る。番号の後ろには名称を付ける（SIST 08、情報処理学会、参照のみ）
2. 図の番号と名称は図の下に、表の番号と名称は表の上に置く（SIST 08、情報処理学会のスタイルファイル、参照のみ）
3. 図表は、本文で番号を挙げて参照する。参照しない図表は置かない

### 句読点

1. 句読点は、共通ルールのNOT-002に従う。投稿先が全角のカンマとピリオドを定めているときは、提出の直前にまとめて置き換え、文書の中で混ぜない（電子情報通信学会、人工知能学会、参照のみ）

### 引用と参考文献

1. 引用の方式は、既定を番号方式にする。本文の該当箇所に、全角の角括弧で「［1］」のように番号を書く（NOT-025）。利用者が著者年方式などを指定したときは、それに従う。一つの文書の中で方式を混ぜない（電子情報通信学会、人工知能学会、参照のみ）
2. 参考文献の既定の書き方は、共通ルールに合わせている（`## 参考文献`の粒度の目安）。投稿先が半角の角括弧や、ピリオドとカンマで区切る書き方を定めているときは、句読点と同じく提出の直前に置き換える
3. 本文で参照した文献はすべて`## 参考文献`に載せ、`## 参考文献`の文献はすべて本文で参照する（人工知能学会、参照のみ）
4. 他者のアイディア、データ、結果、用語を使うときは、出典を示す（文部科学省『研究活動における不正行為への対応等に関するガイドライン』）
5. 文章をそのまま引くときは「」で囲み、出典を付け、原文を変えない。原典を確かめずに、ほかの文献に引かれた文を引かない（著作権法32条、大学図書館の引用の手引き、参照のみ）
