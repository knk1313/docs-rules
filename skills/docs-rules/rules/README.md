# rules/

日本語の文書に共通する表記・文体・Markdown記法のルールを置く。ここに置くのは、`evaluators/score.mjs`で機械的に検査できるルールだけである。

## ファイルの分け方

| ファイル | 内容 | IDのprefix |
| --- | --- | --- |
| [forbidden-words.md](forbidden-words.md) | 使わない言い回しと、その言い換え | `FW-` |
| [grammar.md](grammar.md) | 文法・文体（文末、接続、否定、語の形） | `GRM-` |
| [notation.md](notation.md) | 表記（スペース、英数字、記号、見えない文字） | `NOT-` |
| [markup.md](markup.md) | Markdown記法（見出し、箇条書、コードブロック、リンク、表など） | `MKD-` |

## 1ルールの書き方

各ルールは次の型で書く。項目の順序と名前は変えない。

```markdown
### FW-001 ルールの要約（「〜しない」「〜にする」の形で書く）

- ルール：何をどうするかを1〜2文で書く
- 理由：そのルールで読み手が得をする点を書く
- 出典：資料の略称と該当箇所
- 判定：機械（textlint：<ルール名>）
- 例：「失敗例」→「成功例」
```

- 見出しは`### <ID> <要約>`の形に固定する。`evaluators/score.mjs`はIDで違反を返す
- 項目名の後のコロンは全角の「：」で書き、後ろにスペースを入れない

## IDの採番

- ファイルごとのprefixに3桁の連番を付ける（例：`FW-001`、`GRM-015`、`NOT-022`）
- 削除したルールの番号は再利用しない。番号が飛んでいるのは、使わなくなったルールを消したためである

## 判定の書き方

「判定」は`機械（<ツール>：<ルール名>）`の形で書く。`evaluators/score.mjs`は、この欄からルールIDと判定手段の対応を作る。

- textlintのルール名は、パッケージ名の`textlint-rule-`prefixを除いた形で書く（例：`no-dropping-the-ra`）
- markdownlintのルール名はMD番号で書く（例：`MD004`）
- prh辞書で判定するルールは`機械（textlint：prh）`と書く。辞書の項目にルールIDを書き、採点結果ではそのIDを返す
- `evaluators/custom-rules/`に置いた自前のtextlintルールは、ルール名の前に`docs-rules/`を付ける（例：`機械（textlint：docs-rules/grm-001）`）
- 判定手段が複数あるときは「、」で区切って並べる。ツールが違うときは、ツール名ごとに続けて並べる（例：`機械（markdownlint：MD034、textlint：docs-rules/mkd-010）`）

## 出典の書き方

- 原文の文章は写さず、自分の文章で書き直す。textlintなどのルールセットの説明文やエラーメッセージも写さない
- 複数の資料が根拠になるときは「、」で区切って並べる

各ファイルでは次の略称を使う。

| 略称 | 資料 | 箇所の書き方 |
| --- | --- | --- |
| 公用文作成の考え方 | 文化審議会建議『公用文作成の考え方』（令和4年1月7日） | 建議本文の項目番号（例：`Ⅱ5ウ(イ)`） |
| JTFスタイルガイド | 日本翻訳連盟『JTF日本語標準スタイルガイド』第4.0版 | 第4.0版の本文の項目番号（例：`2.3.1`） |
| textlint | textlint-rule-preset-ja-technical-writing、textlint-rule-preset-jtf-style、textlint-rule-preset-ja-spacing内の各ルール | ルール名（例：`textlint：no-hankaku-kana`） |
| CommonMark Spec | CommonMark Spec 第0.31.2版（2024年1月28日） | 節番号（例：`4.2`） |
| markdownlint | markdownlintの各ルール | MD番号（例：`MD004`） |
| デジタル庁デザインシステム | デジタル庁『デジタル庁デザインシステム』（Markdown版、2026年10月21日版） | ページの名前（例：`リンクテキスト`） |
| 国語審議会の審議経過報告 | 第20期国語審議会『新しい時代に応じた国語施策について（審議経過報告）』（平成7年11月） | 報告の項目番号（例：`Ⅰ4(1)ア`） |

『公用文作成の考え方』と国語審議会の審議経過報告から書き直したルールは、文化庁の資料を基に編集・加工したものである。両資料は文部科学省ウェブサイト利用規約に従う。デジタル庁デザインシステムから書き直したルールは、同資料を基に編集・加工したものである。同資料は公共データ利用規約（PDL1.0）に従う。
