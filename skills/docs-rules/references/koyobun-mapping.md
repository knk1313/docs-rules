# 公用文作成の考え方の取り込み先

文化審議会建議「公用文作成の考え方」（令和4年1月7日）の各項目を、`rules/`のどのルールに取り込んだかを示す対応表。取り込まなかった項目には理由を書く。対応Issueは #10。取り込み方の判断は[reference-sources.md](reference-sources.md)に従う。

## 表の見方

項目番号は建議本文の番号を使う。「取り込み先」には次のどれかを書く。

| 取り込み先 | 意味 |
| --- | --- |
| ルールID | `rules/`の該当ルールに書き直した |
| schemas/ | 文書種別によって基準が変わる。`schemas/`の各種別のファイルで扱う |
| 対象外 | 理由欄の理由で取り込まない |
| 保留 | 取り込むかどうかを決めていない。理由欄に決めるための論点を書く |

- 送り仮名は、建議が認める公用文の書き方（送り仮名を省く語）を採らず、「送り仮名の付け方」の本則に従う
- JTFスタイルガイドと基準が食い違うときは、この表で取り込んだ建議の基準を優先する。JTFスタイルガイドにだけある項目は #12で取り込む
- 構成と内容の層の項目（以前の「prompts/候補」）は、#23で`rules/composition.md`のルール（`CMP-`、`判定：AI`）に書き直すか、`schemas/`か対象外に振り分けた。`CMP-`のルールは`prompts/evaluate.md`の手順で評価する

## 基本的な考え方

| 項目 | 内容（要旨） | 取り込み先 | 理由・備考 |
| --- | --- | --- | --- |
| 1 | 公用文作成の在り方 | CMP-001 | 読み手とのやり取りとして書くという姿勢で、文書全体を読んで判断する |
| 2 | 読み手に伝わる公用文作成の条件（正確・分かりやすさ・気持ちへの配慮） | CMP-001 | 分かりやすさ（伝える内容を絞る）をCMP-001で扱う。正確さは事実関係を知らないと判定できず、気持ちへの配慮はFW-007とCMP-007で扱う |

## Ⅰ 表記の原則

| 項目 | 内容（要旨） | 取り込み先 | 理由・備考 |
| --- | --- | --- | --- |
| Ⅰ1 | 漢字の使い方（常用漢字表の範囲で使う） | NOT-006 | |
| Ⅰ1 | 漢字の使い方（助詞・助動詞・補助的な用法・形式名詞は仮名） | NOT-007 | |
| Ⅰ1 | 漢字の使い方（接続詞・副詞・一部の動詞は仮名） | NOT-008 | |
| Ⅰ1 | 漢字の使い方（「及び」「又は」「並びに」「若しくは」は漢字） | 対象外 | 法令・公用文に特有の書き方のため採らず、「または」「および」と仮名で書く。送り仮名と同じく、公用文固有の慣行は持ち込まない |
| Ⅰ1 | 漢字の使い方（振り仮名の付け方） | 対象外 | Markdownでは振り仮名を付ける記法が定まっていない |

## Ⅱ 用語の使い方

| 項目 | 内容（要旨） | 取り込み先 | 理由・備考 |
| --- | --- | --- | --- |
| Ⅱ1 | 法令・公用文に特有の用語の扱い | 対象外 | 公用文に固有の項目である |
| Ⅱ2 | 専門用語の扱い | CMP-005 | 読み手に合わせて言い換えるかどうかは、読み手と文脈で決まる |
| Ⅱ3 | 外来語への対応 | CMP-005 | 同上 |
| Ⅱ4 | 専門用語や外来語の説明の仕方 | CMP-005 | 同上。略語の説明はNOT-005で扱う |
| Ⅱ5ア(ア) | 同音語による混同を避ける | 保留 | 誤変換の点検に当たり、ルールの形にすると「正しい字を使う」以上の内容がない。evaluators/で辞書を使って判定できるかと合わせて決める |
| Ⅱ5ア(イ) | 異字同訓の漢字を使い分ける | NOT-009 | |
| Ⅱ5イ(ア) | 「から」と「より」を使い分ける | GRM-014 | |
| Ⅱ5イ(イ) | 程度・時期・期間を表す語に注意する | FW-005 | |
| Ⅱ5イ(ウ) | 「等」「など」の前に代表例を挙げる | FW-006 | |
| Ⅱ5ウ(ア) | 表現の重複に注意する | FW-003 | |
| Ⅱ5ウ(イ) | 回りくどい言い方をしない | FW-001、FW-002 | |
| Ⅱ6ア | 読み手に合わせて用語を選ぶ | FW-009、CMP-005 | 硬い漢語はFW-009で扱う。それ以外は読み手と文脈で決まる |
| Ⅱ6イ | 日本語を母語としない人への配慮 | CMP-006 | 読み手を想定して文書全体を読んで判断する |
| Ⅱ6ウ | 敬語の使い方 | FW-007 | |
| Ⅱ6エ | 媒体に応じた表現と品位 | schemas/ | 媒体はほぼ文書種別で決まるため、各種別の「目的と読み手」と「文書全体の制約」で扱う |
| Ⅱ7 | 違和感や不快感を与えない言葉の使い方 | CMP-007 | 文脈を読まないと判断できない |
| Ⅱ8ア | 平易な言葉を使う | FW-009 | |
| Ⅱ8イ | 「漢字一字＋する」の動詞を多用しない | CMP-008 | |
| Ⅱ8ウ・エ | 述部に漢語を使うか、訓読みの動詞を使うかを目的で選ぶ | 対象外 | どちらを選ぶかは文書の目的で決まり、全種別に共通するルールにならない。硬い漢語の言い換えはFW-009で扱う |
| Ⅱ8オ | 紋切り型の表現は効果があるときだけ使う | CMP-009 | |

## Ⅲ 伝わる公用文のために

| 項目 | 内容（要旨） | 取り込み先 | 理由・備考 |
| --- | --- | --- | --- |
| Ⅲ1ア | 目的と相手に応じて常体と敬体を選ぶ | 対象外 | どちらを選ぶかは文書種別ごとに`schemas/`で決める |
| Ⅲ1イ・ウ | 常体と敬体を混ぜない、常体は「である」の形 | GRM-001 | |
| Ⅲ1エ・オ | 文語の言い方を口語にする、「べく」「べし」を使わない | FW-008 | |
| Ⅲ2ア・イ・エ・オ | 標題と見出しで主題と論点が分かるようにする | CMP-003 | 文書種別ごとの見出し名は`schemas/`、見出しの書式はGRM-015とMKD-001〜003で扱う |
| Ⅲ2ウ・カ | 中見出し・小見出しの使い方、見出しを目立たせる工夫 | 対象外 | 見出しの階層はMKD-001で扱う。目立たせ方はMarkdownの表示で決まり、書き手が決めない |
| Ⅲ3ア・イ | 一文を短くし、論点を一つにする | GRM-002 | |
| Ⅲ3ウ | 三つ以上の情報は箇条書にする | GRM-003 | |
| Ⅲ3エ | 基本の語順で書く | GRM-008 | |
| Ⅲ3オ | 主語と述語の関係が分かるようにする | GRM-009 | |
| Ⅲ3カ | 接続助詞や中止法を多用しない | GRM-004 | |
| Ⅲ3キ | 同じ助詞を続けない | GRM-005 | |
| Ⅲ3ク | 修飾節は長いものから並べる | GRM-010 | |
| Ⅲ3ケ | 受身形をむやみに使わない | GRM-007 | |
| Ⅲ3コ | 二重否定を使わない | GRM-006 | |
| Ⅲ3サ | 係る語と受ける語、指示語と指す語を近くに置く | GRM-011 | |
| Ⅲ3シ | 複数の意味に取れる書き方をしない | GRM-012 | |
| Ⅲ3ス | 読点の位置で意味が変わることに注意する | GRM-013 | |
| Ⅲ4イ | 結論を先に示し、理由や詳細は後で示す | CMP-002 | |
| Ⅲ4ア・ウ・エ・オ | 文書の性格に応じた構成、既存の形式、読み手の視点、分量の限度 | schemas/ | 文書種別ごとの必須セクションと粒度の目安で扱う |
| Ⅲ4カ | 「下記」「別記」を使って情報を整理する | 対象外 | 公用文の書式に固有の項目である |

## 確かめた範囲

- 項目番号と要旨は、2026-10-21に文化庁が公開している建議のPDF（本文と解説）で確かめた
- Ⅰ1は、建議本文に細かい項目番号がない。仮名で書く語の範囲は解説のⅠ1(1)〜(3)を基にしたため、出典は「Ⅰ1」までにとどめている
- Ⅱ8のイ〜オ、Ⅲ2とⅢ4の下位項目は、2026-10-23に同じPDFで確かめた
