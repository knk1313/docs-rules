# 論文の一次資料調査

文書種別「論文」（識別名`paper`）を足すために、日本語の論文に固有の構成、文体、表記、引用の規約を調べた結果。対応Issueは#30で、実装は#31で行う。判断の軸（取り込み方、担当する層、ライセンスの扱い）は[reference-sources.md](reference-sources.md)と同じにする。

調査日は2026-10-24。複数の観点でWebを検索し、取り出した主張ごとに3票で反証を試み、2票以上で否定されたものを捨てた。対象は日本語の学会論文、学位論文、紀要で、英語論文は扱わない。

## 候補ごとの判断

### SIST 02とSIST 08

- 判断：参照のみ。SIST事業は2011年度末に終わり、内容はもう更新されない。公式サイトは国立国会図書館のWARPのアーカイブでだけ読める
- ライセンス：サイトの著作物には文化庁の自由利用マーク（プリントアウト・コピー・無料配布）が付いている。このマークは改変や要約を認めないため、文章を書き直して載せる根拠にならない
- 扱い：参考文献の書誌項目の並びと区切り方の知見を、自分の文で書き下ろす。出典にはSIST 02の名前とWARPのURLだけを挙げる。書式の規則そのものが著作権の保護対象外かは、法的には確かめていない
- 現状：人工知能学会の執筆案内と大学図書館は、今もSIST 02（2007年版）を参照先に挙げている
- SIST 08の中身と、科学技術振興機構による後継の資料があるかは確かめられなかった

### 学会と紀要の規定

電子情報通信学会と人工知能学会の和文論文誌の規定を、一次資料で確かめた。どちらも学会の著作物のため参照のみとし、要点だけを書く。

- 構成：要旨（あらまし）、キーワード、本文、謝辞（書く場合だけ）、付録、参考文献、著者紹介を置く。本文は「まえがき、本論、むすび」の順を求めるか推奨し、IMRaD（序論、方法、結果、考察）は定めていない
- 句読点：どちらも全角の「，」「．」を使う。人工知能学会は「、」「。」を使わないと明記している
- 表記：常用漢字と新仮名遣いを使う。人工知能学会は、本文で使う記号に説明を付けるよう求めている
- 引用：電子情報通信学会は番号方式で、本文に半角の「[12]」を書き、上付きにしない。人工知能学会は著者年方式で、「[Quinlan 86]」のように書く
- 要旨の字数：電子情報通信学会のあらましは論文で500字以内である
- 電子情報通信学会のページは取得できず、2025年1月のWayback Machineの版で確かめた

京都産業大学の紀要は、謝辞を独立した節にせず、脚注として書く。引用は著者年方式（「浜田・松本（2010）」）である。一つの紀要の内規のため一般化せず、媒体によって謝辞の位置や要旨の字数が違う例として扱う。

### 文部科学省のガイドライン

- 判断：採用。盗用の定義を、引用のルールの一次の根拠にする
- 要点：盗用は、他の研究者のアイディア、分析方法、データ、研究結果、論文、用語を、了解か適切な表示なしに使うことである。ねつ造、改ざんと並ぶ特定不正行為の一つとされる
- 扱い：定義を自分の文で書き、出典を示す。ガイドラインは引用そのものを定義していないため、「適切な表示（出典）があるか」を盗用との境目として読む

### 国際単位系（SI）

- 判断：採用。数値と単位の書き方の一次資料にする。規則そのものを自分の文で書く
- 要点：数値と単位記号の間に1字分の空白を入れる。例外は平面角の度、分、秒だけで、セルシウス温度には空白を入れる（「30.2 °C」）
- 要点：量記号はイタリック体、単位記号は直立体で書く。単位記号は略語ではないため、ピリオドも複数形の「s」も付けない。「sec」「cc」「mps」のような略し方をしない
- パーセント記号の前に空白を入れるかは、和文誌ごとに慣行が分かれる。媒体の規定に従う
- 日本語版の利用条件は確かめていない

### 引用の実務

- 大学図書館の手引きは、著作権法32条に基づく引用の注意として、必然性、かぎ括弧による区別、自分の文が主であること、出典の明示、原文どおりに写すこと（孫引きをしない）を挙げている
- どちらも二次資料のため参照のみとする。一次の根拠は著作権法32条と文部科学省のガイドラインに置く

## ルール候補

IDの接頭辞は`PAP-`を仮に使う。採否と最終のIDは#31で決める。

| ID候補 | ルール | 判定 | 出典 |
| --- | --- | --- | --- |
| PAP-001 | 題名、著者と所属、要旨、キーワード、本文、謝辞、参考文献、付録の順に置く。付録と参考文献の前後は媒体の規定に従う | 機械（見出しの有無と順序） | 電子情報通信学会、人工知能学会、京都産業大学（参照のみ） |
| PAP-002 | 本文は序論、本論、結論の順にする。IMRaDは分野に応じて使い、必須にしない | 機械（見出し）とAI（各節の役割） | 電子情報通信学会、人工知能学会（参照のみ） |
| PAP-003 | 句読点は媒体の規定に従い、文書の中で「、。」と「，．」を混ぜない | 機械 | 電子情報通信学会、人工知能学会（参照のみ） |
| PAP-004 | 引用は媒体の規定する方式で書き、文書の中で番号方式と著者年方式を混ぜない | 機械 | 電子情報通信学会、人工知能学会（参照のみ） |
| PAP-005 | 参考文献の各項目を本文から参照し、本文の参照先をすべて参考文献に載せる | 機械 | 人工知能学会（参照のみ） |
| PAP-006 | 参考文献には、著者、題名、誌名か書名、発行年、巻号、ページを書く。ウェブの資料には入手先と入手日を加える | 機械（項目の有無） | SIST 02（参照のみ） |
| PAP-007 | 直接の引用は「」で囲んで出典を付け、原文を変えない。孫引きをしない | AI（「」と出典の対応は一部機械） | 著作権法32条、大学図書館の手引き（参照のみ） |

| PAP-010 | 単位記号にピリオドと複数形を付けず、「sec」「cc」「mps」のように略さない | 機械 | SI第9版 |

| 共通ルール | 論文での扱いの案 | 根拠 |

| NOT-002（句点は「。」、読点は「、」） | 媒体が「，．」を定めていれば、それに従う | 電子情報通信学会、人工知能学会 |
| NOT-022（全角と半角の間にスペースを入れない） | 数値と単位の間の空白（PAP-009）は対象外にする。どちらも半角のため、多くの場合は当たらない | SI第9版 |
| GRM-001（常体と敬体を混ぜない） | 論文は常体にそろえる | 未確定。検証を通った一次資料がない |
| GRM-003（三つ以上の項目は箇条書） | 本文では箇条書を多用せず、文で書く | 未確定 |

## 必須セクションの候補

`schemas/paper.md`の下書きに使う。確かめた3媒体に共通する順序を基にした。

| 順 | 見出し名の候補 | 役割 | 必須 |
| --- | --- | --- | --- |
| 1 | 要旨 | 目的、方法、結果、結論を媒体の字数の範囲で示す | 必須 |
| 2 | キーワード | 内容を表す語を媒体の指定する数だけ挙げる | 必須 |
| 3 | 序論 | 背景、課題、先行研究との関係、この論文の目的を示す | 必須 |
| 4 | 本論 | 方法と結果を示す。分野に応じて方法、結果、考察に分ける | 必須 |
| 5 | 結論 | 分かったことと、残った課題を示す | 必須 |
| 6 | 謝辞 | 協力者と資金の出所を示す | 任意 |
| 7 | 参考文献 | 本文で参照した文献を、媒体の方式で並べる | 必須 |
| 8 | 付録 | 本文に入れない詳細を示す | 任意 |

題名と著者は見出しではなく文書の冒頭に置く。英文要旨、英文キーワード、著者紹介は学会論文に固有のため、媒体ごとの設定で足す案を#31に渡す。
