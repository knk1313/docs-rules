# templates/

文書種別ごとの見出しの型を置く。1種別1ファイルで、ファイル名はSKILL.mdの識別名に合わせる（例：`session-log.md`）。必須セクションの定義は[schemas/](../schemas/README.md)を正本とし、ここには見出しの並びと短い案内だけを置く。

## ファイルの分け方

テンプレートのファイルと、対応する種別とスキーマは次のとおり。

| ファイル | 種別 | 識別名 | 対応するスキーマ |
| --- | --- | --- | --- |
| [session-log.md](session-log.md) | セッションログ | `session-log` | [schemas/session-log.md](../schemas/session-log.md) |
| [proposal.md](proposal.md) | 提案書 | `proposal` | [schemas/proposal.md](../schemas/proposal.md) |

## 1種別の書き方

各テンプレートは、次の順に置く。

1. `#`の文書名：埋める箇所を`<>`で示す。中身の例は書かない
2. 冒頭のコメント：対応する`schemas/`のファイルと、案内のコメントを出力に残さない旨を書く
3. 必須セクションの`##`見出し：`schemas/`の必須セクション表の見出し名を、表の順にそのまま並べる
4. 各見出しの直下のコメント：そのセクションに書くことの案内を1行で書く
5. 末尾のコメント：任意の`##`見出しを足せる位置を示す

## 案内の書き方

- 案内はHTMLコメント（`<!-- -->`）で書く。表示したときに見えず、テンプレートを開いても文書の形だけが見える
- 案内は`schemas/`の「書くこと」と「粒度の目安」の要点を、1行の長さで書く。詳しい定義は`schemas/`に書く
- 本文の例文と、空の箇条書などの本文の一部は置かない。例は[rules/examples.md](../rules/examples.md)に置く
- 案内の文も[rules/](../rules/README.md)のルールに従う

## schemas/ との対応の保ち方

- `schemas/`の必須セクション表を直したときは、同じ変更で対応するテンプレートの見出しを直す
- 見出しが表と一致しているかは、リポジトリの`tests/`のテストで確かめる（実行方法はCONTRIBUTING.mdの「テスト」）
