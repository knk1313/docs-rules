# 価値仮説シート

## 取り組みたい社会課題・テーマ

生成AIを利用して文書作成を行う際、文章の構成・情報の粒度にばらつきが生じ、人による確認や修正が必要になっている。

あらかじめ文書作成ルールをコンテキストとして定義し、生成物を機械的またはAIによって評価・改善できる「文書品質保証ハーネス」を構築することで、AIが継続的に一定品質の文書を生成できる環境を実現する。

## ニーズと求める価値の仮説

### 対象者

- AIを利用して、定期的に文書の作成を行っている個人や組織

### ニーズ・欲求

- AIが生成する文書のフォーマットを統一したい
- 見出し構造、文章量、情報の粒度、表記方法を一定にしたい
- 毎回同じ基準をプロンプトへ手作業で記述せず、共通ルールとして管理したい
- 文書がルールに準拠しているか自動的に検査したい
- 内容の網羅性、具体性、信頼性など、形式だけでは判断できない品質も評価したい
- 評価結果をもとに文書を自動修正できるようにしたい
- 文書作成と評価のルールを、再利用可能な資産として蓄積したい

### 課題・困りごと

- Markdownの見出しの記法が統一されない
- 見出し階層やセクション構成が生成のたびに変わる
- セクションごとの情報量や具体性にばらつきがある
- 必須項目の欠落や、同じ内容の重複が発生する
- 文体、用語、日付、出典などの表記が統一されない
- AIへの指示が各プロンプトに分散し、ルールの更新や再利用が難しい
- 人が目視で確認しなければ品質を判断できない
- 何をもって良い文書とするのか、評価基準が明文化されていない
- 定期実行で生成物が増えるほど、修正や品質管理の負担も増加する

### 提供する価値

- Markdownの構文、見出し階層、必須セクションなどをルールとして定義できる
- 構文やフォーマットをコードで自動検査できる
- 内容の具体性、網羅性、論理性、根拠の明確さをAIで評価できる
- 不合格となった文書を、ルールに基づいて自動修正できる
- 定期的に生成する文書を、人の手直しを最小限に抑えながら継続的に蓄積できる
